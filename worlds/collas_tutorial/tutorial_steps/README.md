# Tutorial steps

The CoLLAs 2026 tutorial world, built incrementally: each `stepN/` folder is a complete,
runnable copy of the world at that stage (same runners; the data folder is shared with the main world folder, reached via ../../data), each step adding to the previous one.
See `STEP_README.md` inside each folder.

1. Skeleton (roles + welcome messages)
2. Teacher's streams
3. Actions and behaviors (HSMs)
4. The full classroom
5. Humans as peers (UAI and other embellishments)
6. Introducing stats (and getting the final world)
